# Lígia Rezende · Nutricionista

Landing page da nutricionista **Lígia Rezende**, especialista em Nutrição Clínica
Funcional. Atendimento presencial em Conceição dos Ouros (MG) e online.

🔗 **https://nutriligiarezende.com.br**

## Sobre

Página única, focada em conversão: apresenta a profissional, os planos de
acompanhamento e um formulário em etapas que leva o contato direto pro WhatsApp.

A identidade visual segue o design do Figma: paleta creme, marrom e rosa antigo
(`#c4788a`), verde do WhatsApp nas chamadas de ação, títulos em *Playfair
Display* e texto em *DM Sans*, com cartões em efeito de vidro.

## Tecnologias

- **HTML, CSS e JavaScript puro** — sem framework, sem build
- CSS moderno: variáveis, grid, `backdrop-filter`, `clamp()` para tipografia fluida
- Google Fonts (Playfair Display + DM Sans)
- Hospedagem: **GitHub Pages**

## Estrutura

```
index.html      página completa (HTML + CSS + JS embutidos)
assets/         fotos
```

## Rodar localmente

```bash
python3 -m http.server 8000
```
